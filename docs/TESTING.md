# Проверки версии 0.1.0

## Что проверено при подготовке проекта

Последний прогон: **63 теста прошли**, Python 3.12 / Linux, Qt offscreen. Сборка Python wheel завершилась успешно.

- Установка editable-пакета в Python 3.12, Linux.
- Автотесты парсера команд, JSON-планов, запрета неизвестных инструментов, границ рабочей папки, защиты заметок от перезаписи, локального адреса Ollama.
- Потоковый ответ через HTTP-заглушку, отмена и выгрузка только выбранной модели.
- Модель анимации: ограничение движения, независимость от частоты кадров, возврат из эмоции, заметная реакция на амплитуду.
- Qt offscreen: рисование питомца, отсутствие перекрытия глаз кнопками, чат сохраняется при смене фокуса, Esc закрывает его, отменённый ответ не возвращается в интерфейс.
- Разрешение и скачивание пакетов основных зависимостей для Windows x64 / CPython 3.12. Список версий в `constraints-windows.txt`.
- Синтаксис Python и статические проверки Ruff.

**Не проверено на физической Windows:** Win32-фокус окон, виртуальные столы, звук устройства, SAPI, микрофон, разные сборки Windows и DPI. Успешное разрешение зависимостей не заменяет запуск приложения. Скрипты PowerShell в Linux не исполнялись. Ollama в тестах заменена HTTP-заглушкой; качество ответов зависит от выбранной модели.

## Проверка на Windows после установки

1. `debug.bat`: появились глаза и значок в трее, нет исключений в консоли.
2. Второй запуск не создаёт ещё одного питомца; выход через трей завершает процесс.
3. Нажать на глаза, открыть чат, переключиться в другое приложение: чат и текущий запрос сохраняются.
4. Написать `открой браузер`; браузер открывается/показывается, сообщение соответствует фактическому результату.
5. `открой стим` при установленном Steam. Если запуск медленный, NOVA сообщает о неподтверждённом окне, не запускает второй экземпляр.
6. `переключись на рабочий стол 3`; проверить Win+Tab. Кнопкой ◇/◆ проверить следование и закрепление. Неудача должна дать сообщение, а не «готово».
7. Включить музыку. Проверить `что играет`, `пауза`, `продолжи музыку`, `следующий трек`. При игре наушники следуют за глазами, пульсация зависит от звука.
8. `громкость 30`, `сделай тише на 10`, `выключи звук`, `включи звук` — сравнить с микшером Windows.
9. В настройках выбрать скачанную модель, написать `привет`, затем `кто ты?`: потоковый осмысленный ответ либо явная ошибка соединения/модели.
10. Запустить запрос, нажать Esc. Нет позднего возвращения ответа и речи. После завершения отмены `ollama ps` не должен показывать выбранную модель, если другие приложения её не используют.
11. Включить прогретый режим, повторить пункт 10: явный выход всё равно запрашивает выгрузку.
12. «План»: попросить открыть браузер и поставить таймер. До OK ничего не запускается. Cancel ничего не выполняет.
13. Выбрать SAPI-голос, проверить русский текст и «Стоп» во время речи.
14. Настроить Vosk, записать фразу, проверить текст перед отправкой. Esc/Стоп прекращает запись.
15. Переместить питомца, перезапустить: положение восстановлено. Проверить масштаб 100/150/200% и другой монитор.
16. Включить/убрать автозапуск; проверить ярлык NOVA в папке Startup.

При сбое приложи вывод `scripts/doctor.py` и сообщение ошибки из `nova.log`. В журнал не записывается содержимое чата; отчёт doctor содержит пути и названия установленных голосов/моделей — просматривай его перед публикацией.
