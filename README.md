# NOVA — настольный помощник для Windows 11

NOVA — питомец с зелёными светящимися глазами, локальным ИИ, голосом и инструментами управления компьютером.

Работает отдельным приложением, без Kitty и GNOME.

## Возможности

- Открытие приложений по обычным названиям: «браузер», «стим», «блокнот».
- Управление окнами и переключение виртуальных рабочих столов.
- Управление музыкой и общей громкостью Windows.
- Чат через Ollama с выбором установленной модели.
- Озвучка ответов голосом Windows.
- Необязательный голосовой ввод через микрофон.
- Выполнение составных задач после просмотра и подтверждения плана.
- Диагностика загрузки компьютера, таймеры и текстовые заметки.
- Плавные движения глаз, самостоятельные эмоции и реакция на музыку.
- Перетаскивание питомца, закрепление положения и меню в системном трее.

**Статус:** первая версия для Windows. Логика и интерфейс проверены автоматическими тестами в Linux. Полная работоспособность нативных функций на разных сборках Windows ещё требует проверки.

---

## 1. Требования

- Windows 11 x64.
- Python 3.12 x64 с Python Launcher `py`. Также поддерживается Python 3.11.
- Git.
- Интернет для загрузки программы, зависимостей и моделей.
- Ollama — для общения с ИИ и составления планов.

**Базовые команды Windows работают без Ollama.**

Python 3.13 и новее текущий установщик не поддерживает. Windows ARM не проверена.

Размер нужной оперативной памяти и свободного места зависит от выбранной модели. Модели устанавливаются отдельно от NOVA.

## 2. Установка Python, Git и Ollama

Открой меню «Пуск», введи **PowerShell** и запусти его.

Выполняй команды по очереди. После каждой команды дождись завершения установки.

### Python 3.12

```powershell
winget install --id Python.Python.3.12 --exact --source winget --architecture x64 --accept-source-agreements --accept-package-agreements
```

### Git

```powershell
winget install --id Git.Git --exact --source winget --accept-source-agreements --accept-package-agreements
```

### Ollama

```powershell
winget install --id Ollama.Ollama --exact --source winget --accept-source-agreements --accept-package-agreements
```

Если появляется окно установщика или запрос Windows на разрешение установки, следуй его подсказкам.

**После установки полностью закрой PowerShell или Windows Terminal и открой заново через меню «Пуск».** Это нужно, чтобы терминал увидел установленные программы.

Проверь:

```powershell
py -3.12 --version
git --version
ollama --version
```

Команды должны показать версии программ. Для Ollama также может появиться предупреждение, если её сервер ещё не запущен.

### Если `winget` не найден

Установи или обнови **App Installer / «Установщик приложений»** через Microsoft Store, затем заново открой терминал.

Либо используй официальные установщики:

- Python: https://www.python.org/downloads/windows/
- Git: https://git-scm.com/downloads/win
- Ollama: https://ollama.com/download/windows

При ручной установке Python выбери **Python 3.12 x64** и включи компонент **Python Launcher**. Также отметь **Add python.exe to PATH**, если установщик предлагает этот пункт.

## 3. Скачивание и установка NOVA

В новом окне PowerShell создай папку для проектов:

```powershell
New-Item -ItemType Directory -Force -Path "$HOME\code"
Set-Location "$HOME\code"
```

Склонируй репозиторий:

```powershell
git clone https://github.com/liptonn405/nova-windows.git
```

Перейди в папку проекта:

```powershell
Set-Location "$HOME\code\nova-windows"
```

Запусти установку:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

Установщик создаст отдельное окружение `.venv` и установит необходимые библиотеки.

Дождись сообщения:

```text
NOVA installed. Run start.bat.
```

Если установка завершилась ошибкой, сначала исправь её. Не переходи к запуску программы.

Параметр `ExecutionPolicy Bypass` действует только для запущенного процесса PowerShell. Постоянную системную политику он не меняет.

### Если проект скачан ZIP-архивом

Распакуй архив, открой PowerShell в папке, содержащей `install.ps1`, и выполни ту же команду установки. Повторно клонировать репозиторий не нужно.

## 4. Первый запуск

В папке проекта выполни:

```powershell
.\start.bat
```

На рабочем столе появится NOVA. В системном трее, рядом с часами Windows, появится значок с зелёными глазами.

- Нажми на питомца или кнопку `···`, чтобы открыть чат.
- Перетащи питомца мышью, чтобы изменить положение.
- Открой меню `≡`, чтобы перейти в настройки.
- Если значок в трее скрыт, нажми стрелку возле часов.
- Для полного завершения выбери **«Выход»** в меню трея.

При следующих запусках достаточно открыть `start.bat` двойным щелчком. Повторная установка не нужна.

## 5. Запуск Ollama и установка модели

Открой меню «Пуск» и запусти **Ollama**.

Она работает в фоне и предоставляет локальный API:

```text
http://127.0.0.1:11434
```

В PowerShell скачай **одну модель на выбор**:

| Модель | Команда | Особенности |
|---|---|---|
| Qwen3 1.7B | `ollama pull qwen3:1.7b` | Меньше ресурсов, но слабее ответы и сложные планы |
| Qwen3 4B | `ollama pull qwen3:4b` | Исходный вариант NOVA |
| Qwen3 8B | `ollama pull qwen3:8b` | Более требовательная модель; на CPU может работать медленно |

Например:

```powershell
ollama pull qwen3:4b
```

Дождись окончания загрузки. Все модели из таблицы скачивать не нужно.

Посмотреть установленные модели:

```powershell
ollama list
```

Проверить выбранную модель отдельно от NOVA:

```powershell
ollama run qwen3:4b
```

Напиши `Привет`. Для выхода из этого диалога введи:

```text
/bye
```

### Выбор модели в NOVA

1. Открой настройки NOVA.
2. Нажми **«Обновить список»**.
3. В поле **«Модель»** выбери скачанный тег, например `qwen3:4b`.
4. Нажми **«Сохранить»**.
5. Открой чат и напиши `Привет`.

Можно использовать другую совместимую текстовую модель Ollama: сначала скачай её командой `ollama pull`, затем выбери в NOVA.

Не каждая модель одинаково хорошо справляется с составлением JSON-планов. Для обычного общения и для управления через «План» качество может различаться.

### Если Ollama не запущена

Запусти её через меню «Пуск».

Альтернативно открой отдельное окно PowerShell:

```powershell
ollama serve
```

Оставь это окно открытым, пока используешь ИИ.

Если команда сообщает, что порт `11434` уже занят, возможно, Ollama уже работает. Проверь:

```powershell
ollama list
```

## 6. Примеры команд

Простые команды выполняются без ожидания ответа модели.

| Запрос | Действие |
|---|---|
| `открой браузер` | Ищет Chromium, Chrome, Firefox или Edge и открывает либо показывает окно |
| `открой стим` | Запускает установленный Steam |
| `открой блокнот` | Открывает Блокнот |
| `покажи приложения` | Показывает обнаруженные приложения |
| `покажи окна` | Показывает видимые окна |
| `разверни окно Chromium` | Разворачивает найденное окно |
| `сверни окно Блокнот` | Сворачивает найденное окно |
| `переключись на рабочий стол 3` | Переключает на третий стол; создаёт недостающие столы |
| `следующий трек` | Переключает трек вперёд |
| `предыдущий трек` | Переключает трек назад |
| `пауза` | Ставит музыку на паузу |
| `продолжи музыку` | Возобновляет воспроизведение |
| `что играет` | Показывает исполнителя и название трека |
| `громкость 30` | Устанавливает громкость 30% |
| `сделай тише на 10` | Уменьшает громкость на 10 процентных пунктов |
| `выключи звук` | Отключает звук |
| `включи звук` | Включает звук |

| `найди в интернете Python` | Открывает поиск в браузере |

Если подходят несколько приложений или окон, NOVA попросит уточнить название.

Портативные программы, которые не зарегистрированы в Windows и не имеют ярлыка в меню «Пуск», могут не обнаружиться автоматически.

## 7. Составные задачи: кнопка «План»

Для нескольких действий напиши задачу:

```text
Открой браузер, установи громкость 25 и поставь таймер на 20 минут.
```

Нажми **«План»**.

NOVA:

1. Запросит план у выбранной модели.
2. Проверит допустимость инструментов и аргументов.
3. Покажет список действий.
4. Выполнит их после подтверждения кнопкой OK.

При отмене плана действия не выполняются. При ошибке одного шага дальнейшее выполнение прекращается. Уже выполненные шаги автоматически не откатываются.

Пример создания заметки:

```text
Создай заметку план.md с текстом: повторить указатели и решить три задачи.
```

Заметка создаётся в рабочей папке, выбранной в настройках. По умолчанию это `Documents\NOVA` внутри домашней папки пользователя.

Существующие заметки не перезаписываются.

### Границы возможностей

NOVA использует конкретные инструменты управления Windows. Она не может произвольно нажимать любые кнопки в любых приложениях.

Модели не предоставляется выполнение произвольных команд PowerShell, Python или командной строки. Удаление файлов и отправка сообщений не реализованы.

Чтение файлов ограничено выбранной рабочей папкой, текстовыми форматами и размером до 64 КБ.

## 8. Голосовые ответы

Для озвучки используется **Windows SAPI**. Отдельную нейросетевую модель голоса скачивать не нужно.

В настройках NOVA:

1. Включи **«Озвучивать ответы»**.
2. Выбери голос.
3. Настрой темп речи.
4. Сохрани настройки.

Для русского текста нужен русский голос, доступный через SAPI. Не все голоса, отображаемые в настройках Windows или экранного диктора, доступны сторонним приложениям через SAPI.

Если подходящего голоса нет, проверь установленные речевые компоненты Windows и снова открой список голосов NOVA.

Точный голос Джарвиса или актёра в проект не включён.

Озвучка начинается после получения полного текстового ответа. Во время речи глаза анимируются; это визуальная стилизация, а не точная синхронизация с фонемами.

Кнопка **«Стоп»**, Esc и выход из чата останавливают озвучку.

## 9. Голосовой ввод через микрофон

Голосовой ввод необязателен и работает локально через Vosk.

В PowerShell перейди в папку проекта:

```powershell
Set-Location "$HOME\code\nova-windows"
```

Установи поддержку микрофона и русскую модель распознавания:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup-voice.ps1
```

Скрипт установит зависимости и скачает небольшую русскую модель с официального сайта Vosk.

После завершения он покажет путь к папке модели. Обычно:

```text
C:\Users\ИМЯ_ПОЛЬЗОВАТЕЛЯ\code\nova-windows\models\vosk-model-small-ru-0.22
```

В настройках NOVA укажи эту папку в поле **«Папка модели Vosk»** и сохрани настройки.

### Использование

1. Открой чат.
2. Нажми **«Микрофон»**.
3. Дождись приглашения говорить.
4. Произнеси команду.
5. Проверь распознанный текст в поле ввода.
6. Нажми ↑ для отправки.

Запись заканчивается после распознанной фразы либо через 12 секунд. Постоянного прослушивания нет.

### Если микрофон не работает

Проверь в Windows:

**Параметры → Конфиденциальность и безопасность → Микрофон.**

Разреши доступ к микрофону, в том числе классическим приложениям.

Посмотреть устройства:

```powershell
.\.venv\Scripts\python -m sounddevice
```

В настройках NOVA:

- `−1` — микрофон по умолчанию.
- Другой номер — индекс устройства из списка.

## 10. Питомец и рабочие столы

- Перетаскивание мышью меняет положение NOVA.
- В меню можно включить **«Зафиксировать положение»**.
- Кнопка `◇ / ◆` переключает следование между рабочими столами и закрепление на текущем столе.
- Следование реализовано через отображение окна на всех рабочих столах Windows, без отдельной анимации перелёта.
- Движения глаз ограничены по амплитуде.
- После короткого внимания к мыши возвращаются самостоятельные взгляды и эмоции.
- При низком заряде может появляться сонная эмоция.
- При активной музыке появляются наушники, которые двигаются вместе с глазами.
- Пульсация использует уровень реального системного звука. Это реакция на амплитуду, а не определение музыкального BPM.
- Таймеры работают, пока NOVA запущена.

Обычная анимация рассчитана примерно на 60 кадров/с, сон — на 10 кадров/с. Фактическая частота зависит от нагрузки компьютера.

## 11. Скорость ИИ и использование памяти

Быстродействие зависит от модели, CPU, GPU, свободной RAM и длины контекста.

Если ответы медленные:

1. Проверь, не закончилась ли свободная оперативная память.
2. Выбери меньшую модель, например `qwen3:1.7b`.
3. Закрой тяжёлые приложения.
4. При достаточной RAM включи **«Держать модель в памяти между запросами»**.

Этот переключатель уменьшает задержку повторной загрузки модели, но занимает память. Саму генерацию большой модели на слабом процессоре он не делает мгновенной.

### Выход из режима ИИ

Нажатие **Esc / Назад**:

- Закрывает чат.
- Останавливает озвучку.
- Отменяет текущий запрос.
- Очищает историю беседы.
- Запрашивает выгрузку выбранной модели из Ollama.

При активном сетевом запросе отмена может занять время до тайм-аута чтения, после чего выполняется запрос выгрузки.

Переключение в другое приложение или на другой рабочий стол чат не закрывает.

Проверить загруженные модели:

```powershell
ollama ps
```

При необходимости вручную выгрузить конкретную модель:

```powershell
ollama stop qwen3:4b
```

Общий сервер `ollama serve` NOVA не завершает: им могут пользоваться другие программы. Процесс сервера может оставаться после выгрузки модели. Другое приложение также может загрузить модель повторно.

## 12. Автозапуск

Чтобы NOVA запускалась при входе в Windows:

```powershell
Set-Location "$HOME\code\nova-windows"
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\autostart.ps1
```

Чтобы убрать автозапуск:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\autostart.ps1 -Remove
```

Настройка относится только к текущему пользователю.

## 14. Частые ошибки

### `py` не найден или Python не подходит

Полностью закрой терминал и открой заново.

Проверь:

```powershell
py -3.12 --version
```

Если команда недоступна, проверь установку Python 3.12 x64 и компонента Python Launcher.

### `git` или `ollama` не найдены

Открой новый терминал после установки программы.

Проверь:

```powershell
git --version
ollama --version
```

### `install.ps1` не найден

Ты находишься не в папке проекта.

```powershell
Set-Location "$HOME\code\nova-windows"
Get-ChildItem
```

В списке должен быть файл `install.ps1`.

Если проект расположен в другой папке, используй её настоящий путь.

### Не удаётся подключиться к Ollama

Запусти Ollama через меню «Пуск» или в отдельном терминале:

```powershell
ollama serve
```

Затем:

```powershell
ollama list
```

В настройках NOVA проверь адрес:

```text
http://127.0.0.1:11434
```

### Модель не найдена

Скачай её:

```powershell
ollama pull qwen3:4b
```

В настройках NOVA выбери точно такой же тег, как в выводе:

```powershell
ollama list
```

### NOVA не появилась после запуска

Запусти диагностический вариант из папки проекта:

```powershell
.\debug.bat
```

Он оставляет консоль открытой, чтобы можно было увидеть ошибку.

Также проверь системный трей: возможно, NOVA уже запущена.

### Нет звука

Проверь:

- Включена ли озвучка в настройках NOVA.
- Доступен ли выбранный SAPI-голос.
- Не отключён ли звук Windows.
- Правильно ли выбрано устройство вывода.
- Завершилась ли генерация текстового ответа.

### Не работает переключение музыки

Плеер должен предоставлять медиасессию Windows SMTC.

Начни воспроизведение музыки и повтори команду. Поддержка зависит от приложения или браузера.

Кнопка «Нравится» для Яндекс Музыки в этой версии не реализована.

### Не переключаются рабочие столы

Поддержка виртуальных столов зависит от сборки Windows и совместимости `pyvda`.

При ошибке используй Win+Tab и сохрани текст ошибки для отчёта. NOVA не должна сообщать об успешном переключении, если оно не подтверждено.

### В GitHub Actions ошибка `libEGL.so.1`

Это отсутствие графической библиотеки в Linux-окружении CI.

Такая ошибка препятствует запуску Qt-тестов на Ubuntu. Она сама по себе не доказывает наличие или отсутствие ошибок Windows.

Состояние Windows-проверок нужно смотреть отдельно.

## 15. Диагностика

Выполни из папки проекта:

```powershell
.\.venv\Scripts\python .\scripts\doctor.py
```

Отчёт показывает версии, доступность зависимостей, моделей Ollama и голосов Windows.

Настройки:

```text
%LOCALAPPDATA%\NOVA\settings.json
```

Журнал ошибок:

```text
%LOCALAPPDATA%\NOVA\nova.log
```

Открыть папку с ними:

```powershell
explorer "$env:LOCALAPPDATA\NOVA"
```

Тексты чата не записываются в журнал. Перед публикацией диагностического отчёта проверь содержащиеся в нём пути и названия моделей.

powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Dev

## 17. Удаление

1. Убери автозапуск:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\autostart.ps1 -Remove
```

2. Закрой NOVA через меню трея.
3. Удали папку проекта.

Настройки, созданные заметки и модели Ollama остаются отдельно. Удаляй их только при необходимости.

Удалить конкретную модель Ollama:

```powershell
ollama rm qwen3:4b
```

Эта команда удаляет скачанную модель, а не NOVA.
