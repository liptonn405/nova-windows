# NOVA для Windows 11

Локальный настольный питомец с зелёными светящимися глазами, чатом Ollama, голосом и инструментами управления Windows. Работает отдельно от терминала и GNOME.

**Статус: первая переносимая версия 0.1.0.** Логика и Qt-интерфейс проверены автоматическими тестами в Linux. Управление реальными окнами, звук, микрофон и виртуальные столы требуют проверки на Windows 11; список проверок — [docs/TESTING.md](docs/TESTING.md). Это исходный проект, не подписанный готовый EXE. Модели и Python в репозиторий не включены.

## Быстрый запуск после клонирования

Нужны **Windows 11 x64**, **Python 3.12 x64** (также поддерживается 3.11) с компонентом Python Launcher `py` и Git. Устанавливать NOVA от администратора не нужно. Python 3.13+ и Windows ARM в этой версии не проверены.

- Python: https://www.python.org/downloads/windows/
- Git: https://git-scm.com/downloads/win
- Ollama: https://ollama.com/download/windows

В PowerShell:

```powershell
# Подставь реальный URL опубликованного репозитория:
git clone <URL_РЕПОЗИТОРИЯ> nova-windows
cd nova-windows
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
.\start.bat
```

Если получил ZIP, распакуй его и открой PowerShell в папке `nova-windows`; начни с команды установки. `ExecutionPolicy Bypass` действует только на запущенный процесс установщика, системную политику он не изменяет. Скрипт создаёт `.venv` и устанавливает зависимости. Повторный запуск обновляет зависимости в этом окружении.

При первом запуске NOVA появляется справа снизу; меню доступно у глаз и в системном трее. Нажми на питомца или `···`, чтобы открыть чат. Перетащи питомца мышью. Через меню можно зафиксировать положение.

Репозиторий в этом архиве ещё не опубликован: URL выше — место для твоей ссылки. Для публикации создай пустой репозиторий на выбранном Git-хостинге и выполни инструкции из [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

## Ollama и выбор модели

1. Установи Ollama по официальной ссылке и запусти из меню «Пуск». Она предоставляет локальный API `http://127.0.0.1:11434`.
2. Открой новый PowerShell и скачай **одну** модель на выбор:

| Вариант | Команда | Когда выбирать |
|---|---|---|
| Qwen3 1.7B | `ollama pull qwen3:1.7b` | Меньше памяти и более простые задачи; хуже сложные планы |
| Qwen3 4B | `ollama pull qwen3:4b` | Исходный вариант NOVA, баланс качества и размера |
| Qwen3 8B | `ollama pull qwen3:8b` | Более сложные ответы, если хватает памяти; на CPU может быть медленно |
| Своя модель | `ollama pull ИМЯ_МОДЕЛИ` | Любая совместимая текстовая модель Ollama |

Это выбор, а не обязательная установка всех моделей. Скорость зависит от процессора, GPU, свободной RAM и размера контекста; одинаковая скорость на разных ПК не обещается.

3. В NOVA открой **Настройки → Обновить список → Модель** и выбери скачанную модель. Можно вписать тег вручную. Нажми «Сохранить».
4. Напиши «привет». Обычный ответ появляется частями по мере генерации.

Диагностика Ollama:

```powershell
ollama list
ollama ps
ollama run qwen3:4b
```

Если Ollama не запущена, открой её из «Пуска» либо выполни `ollama serve` в отдельном терминале. Ошибка занятого порта при `serve` часто означает, что сервер уже запущен. NOVA не скачивает многогигабайтные модели без команды пользователя.

### Скорость и освобождение памяти

- Простые команды Windows выполняются **без модели**. Слабая модель не нужна для «открой браузер» или «стол 3».
- Контекст ограничен, скрытое рассуждение у Qwen3 отключено, ответы ограничены по длине.
- «Держать модель в памяти» ускоряет следующий запрос ценой занятой RAM. По умолчанию выключено.
- **Esc / Назад** закрывает чат, останавливает озвучку, отменяет запрос, очищает историю беседы и посылает Ollama выгрузку выбранной модели. При активном HTTP-запросе отмена может занять до тайм-аута чтения (20 секунд), затем выполняется выгрузка.
- Смена активного окна, рабочего стола или сворачивание **не закрывает чат**.
- Общий `ollama serve` не завершается: им могут пользоваться другие приложения. Маленький процесс сервера может остаться. Если другая программа использует ту же модель, она может загрузить её снова.
- При недоступном сервере выгрузку нельзя подтвердить. Проверка — `ollama ps`.

## Команды и агент

| Напиши | Что делает NOVA |
|---|---|
| `открой браузер` | Ищет Chromium, Chrome, Firefox, Edge; открывает или показывает существующее окно |
| `открой стим` | Ищет установленный Steam |
| `открой блокнот` | Запускает Блокнот |
| `покажи приложения` | Показывает найденные приложения Windows |
| `покажи окна` | Показывает видимые окна |
| `разверни окно Chromium` | Разворачивает однозначно найденное окно |
| `сверни окно Блокнот` | Сворачивает выбранное окно |
| `переключись на рабочий стол 3` | Переключает на третий стол; создаёт недостающие столы |
| `следующий трек`, `предыдущий трек` | Отправляет команду активному медиаплееру Windows |
| `пауза`, `продолжи музыку`, `что играет` | Управляет воспроизведением / читает название трека |
| `громкость 30`, `сделай тише на 10` | Меняет общую громкость Windows |
| `выключи звук`, `включи звук` | Переключает mute |
| `проверь компьютер` | CPU, доступная RAM, свободный диск, батарея, пять самых крупных процессов |
| `таймер 25 минут` | Локальный таймер с уведомлением, пока NOVA работает |
| `покажи файлы` | Файлы выбранной рабочей папки |
| `прочитай файл README.md` | Читает небольшой текстовый файл из рабочей папки |
| `найди в интернете погоду в Петербурге` | Открывает поиск в браузере; не выдаёт непроверенный прогноз |

Указание точного названия не обязательно для известных псевдонимов («браузер», «стим», «блокнот»). Для остальных приложений используются записи меню «Пуск», App Paths и зарегистрированные приложения. При неоднозначности NOVA просит уточнить. Портативные программы, которые нигде не зарегистрированы, могут не обнаружиться.

Для составной задачи введи, например:

> Открой браузер, поставь громкость 25 и поставь таймер на 20 минут.

Нажми **План**. Модель предложит до шести действий. NOVA проверит имена инструментов и аргументы, покажет весь план и выполнит его после нажатия OK. При ошибке шага дальнейшие шаги прекращаются; предыдущие выполненные действия не откатываются автоматически.

Через «План» также можно создать новую заметку:

> Создай заметку план.md с текстом: повторить указатели и решить три задачи.

Это **ограниченный агент с инструментами**, а не универсальное управление произвольным интерфейсом. Модель не получает shell, не исполняет Python/PowerShell по своему усмотрению, не удаляет файлы и не отправляет сообщения. Просмотр файлов ограничен выбранной рабочей папкой; заметки не перезаписывают существующие файлы. Содержимое файлов по команде чтения показывается пользователю и не отправляется модели автоматически.

После команды показывается результат адаптера Windows. Если запуск был запрошен, но фокус или смену трека подтвердить нельзя, NOVA так и сообщает, вместо безусловного «готово».

## Голос и микрофон

**Озвучка:** встроенный движок Windows SAPI; не нужна дополнительная тяжёлая TTS-модель. В настройках включи озвучку, выбери доступный голос и темп. Список содержит именно SAPI-голоса, доступные приложениям, а не все голоса Windows Narrator. Для русского текста нужен доступный русский SAPI-голос. Если его нет — установи речевой пакет Windows и проверь список снова. Точный голос актёра/Джарвиса в проект не включён.

Голос начинается после завершения текстового ответа, произносит его целиком. Глаза анимируются во время речи; это стилизация, не фонемная синхронизация. «Стоп», Esc и выход из программы отменяют озвучку.

**Ввод голосом:** необязательный, офлайн, Vosk. Установка:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup-voice.ps1
```

Скрипт ставит `vosk` и `sounddevice`, скачивает небольшую русскую модель с официального сайта. Затем в настройках NOVA укажи выведенную папку `models\vosk-model-small-ru-0.22`.

Нажми **Микрофон**, произнеси фразу. Запись завершается после фразы либо через 12 секунд. Распознанный текст появляется в поле: проверь и нажми ↑. Постоянного прослушивания и слова активации нет. Модель распознавания загружается по кнопке и освобождается после записи.

Если запись не работает, проверь разрешение микрофона для классических приложений в настройках Windows. Устройство по умолчанию: −1. Список устройств:

```powershell
.\.venv\Scripts\python -m sounddevice
```

## Живой питомец

- Прозрачное окно поверх рабочего стола, перетаскивание и фиксация положения.
- Кнопка `◇ / ◆`: следовать между столами / оставаться на текущем. Реализовано через закрепление окна Windows, не через отдельную анимацию перелёта.
- Плавное движение глаз с ограничением, краткое внимание к мыши, затем самостоятельные взгляды, подмигивания, удивление; при низком заряде — сонная эмоция.
- Наушники нарисованы в той же системе координат, что глаза: двигаются вместе.
- При активной медиасессии глаза пульсируют по **уровню реального системного звука** через Core Audio. Это реакция на амплитуду, не распознавание BPM. При недоступном измерителе выдуманного «бита» нет.
- Иконка батареи расположена в отдельной верхней строке, вне области глаз.
- Анимация запрашивает около 60 кадров/с, сон — 10 кадров/с; фактическая частота зависит от нагрузки Windows.
- Меню в трее, защита от запуска второй копии, таймеры, сохранение положения и настроек.

Это самостоятельный Windows-порт базового образа NOVA. GNOME-расширение, Kitty-хуки ввода, старые модели клонирования голоса и все прежние секретные сценки из Linux не переносятся автоматически.

## Автозапуск, обновление, удаление

```powershell
# Автозапуск для текущего пользователя, без прав администратора:
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\autostart.ps1

# Убрать автозапуск:
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\autostart.ps1 -Remove
```

Обновление: закрой NOVA через трей → `git pull` → повторно запусти `install.ps1`. Настройки отдельно от репозитория: `%LOCALAPPDATA%\NOVA\settings.json`. Журнал ошибок: `%LOCALAPPDATA%\NOVA\nova.log`; тексты бесед не журналируются.

Удаление: убери автозапуск, закрой NOVA, удали папку проекта. Настройки, рабочие заметки и модели Ollama остаются; удали их отдельно только при необходимости.

## Ограничения Windows и диагностика

- Управление виртуальными столами использует `pyvda` и зависит от сборки Windows. При несовместимости остаётся Win+Tab; ошибки не маскируются. Переход на повышенные права для обхода ограничений не выполняется.
- Windows может запретить перевод чужого окна на передний план. NOVA сообщает, если фокус не подтверждён.
- Музыка работает с приложениями, которые предоставляют Windows SMTC-медиасессию. В Яндекс Музыке это зависит от приложения/браузера. **Лайк трека не реализован:** стандартная медиасессия не даёт универсальной кнопки «нравится».
- Не обещается непрерывная работа над экраном блокировки, UAC или окнами администратора.
- Модель слышит/видит только то, что передано через интерфейс. Непрерывного захвата экрана нет.
- История чата только в RAM; закрытие чата её очищает. Ollama — локальная; удалённые API-адреса этой версией не принимаются.
